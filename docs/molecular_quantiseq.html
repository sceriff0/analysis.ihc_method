Rmd 09313c1 sceriff0 2026-10-07 :sparkles: quanTIseq page: IHC fraction over each arm’s whole slide and annotation

Arms: massimo1 and massimo2, one method: quanTIseq. The per-arm molecular pages compare every deconvolution method against one arm’s whole slide. This page turns that around: one method, and every cell set the IHC fraction can be taken over — each arm’s whole slide, and the cells inside each arm’s pathologist annotation. The two arms’ annotations are different polygons over the same tissue, so panels are compared by PATIENT, never region by region.

One question, asked once per population quanTIseq can estimate: does the quanTIseq fraction from bulk RNA track the fraction of cells the IHC panel counts, and does the answer depend on which cells are counted?

Shared keys: the id bridge and the hot/cold call

Bulk RNA is keyed by CRF id and IHC by slide id. crf2slide maps one to the other (crf_to_slide_map() over data/clinical_data.xlsx: ID CRF PRESERVE to ID PATIENT), and clin carries the clinical Immuno-phenotype used to colour every point below. The line printed is the number of clinical rows and how many carry each of the two immune columns.

quanTIseq on the bulk RNA

quanTIseq is run by immunedeconv::deconvolute() on the gene-by-sample matrix from data/counts.RData, on the TPM scale when gene lengths were found and on the DESeq2-normalised scale otherwise (expr_scales, built in code/load_data.R; quanTIseq was fit on TPM, so the printed scale matters for absolute values and much less for the cross-patient ranking used here). The result is one fraction per cell type and sample, keyed into slide space with crf2slide; samples with no slide are dropped and counted in the printed line.

Which quanTIseq cell type is compared with which IHC population

Each quanTIseq label is assigned to the IHC populations it can be compared with by deconv_contributions() (code/validation_helpers.R), the same rules the per-arm molecular pages print in full. A label either is a population (its direct match) or is summed into a composite; quanTIseq’s fractions are of all cells, so its labels may be added. The B-cell and myeloid labels have no direct match because the IHC panel has no B or myeloid marker — they are compared only as their sum, Immune_other.

Which cells the IHC fraction is taken over

The IHC fraction is computed four times, once per scope in DECONV_SCOPES (code/deconv_scopes.R). The table is that registry, with the number of cells each scope’s arm has on disk (ihc_for(arm): one row per physical cell per patient — data/massimo1/FlowPath_csv_all/ for massimo1, the pooled and de-duplicated data/massimo2/csv/ for massimo2).

Three things to hold on to when reading across scopes:

  • The two whole-slide scopes are different numbers. The arms gate the same slides at different thresholds, so the same slide has a different CD8T fraction in each.
  • massimo1 has one annotation scope. Its annotation_all polygon is the exact union of that patient’s annotation_selected regions, so a separate scope for the selected regions would redraw the same cells.
  • A slide with no polygon in a scope’s set is cut by FlowPath’s own inside/outside call — the Out_of_annotation column of that slide’s csv. This is the rule for this page only: the clinical pages count such a massimo2 slide whole.

For each scope, every cell of the arm is marked inside or outside: by point-in-polygon of its centroid against the scope’s polygon set (sf), or by the csv’s Out_of_annotation flag where the patient has no polygon in that set (flag); a whole-slide scope keeps every cell (all_cells). The table counts, per scope and patient, the cells the arm holds and the cells the scope keeps, and names the rule that decided.

quanTIseq vs IHC, per population and scope

For each scope, the quanTIseq score of a population (the sum of the labels the mapping table assigns to it) is inner-joined on patient and population to that scope’s IHC fraction (deconv_pair_with_ihc()). Agreement is the cross-patient Spearman correlation (paired_spearman(): NA under 3 patients or when either side is constant). Each cell of the table is rho with the number of patients it was computed over.

qs_paired <- scope_frac |>

            mutate(scope = f$scope[1], .before = 1)) |>
  left_join(clin, by = "patient_id")

One scatter per population

One tab per scope, and inside it one figure per population in the gate tree’s order. Each point is a patient: x is the IHC fraction of all cells the scope keeps (FlowPath phenotypes from that scope’s arm), y is the quanTIseq fraction from that patient’s bulk RNA. Both are fractions of all cells, so the dashed grey line is x = y; the blue line is a least-squares fit drawn to show direction only. Points are coloured by the clinical Immuno-phenotype. The title carries the population’s gate, the subtitle the scope, its Spearman rho and its n. Each plot is exported as its own PDF.

Notes

  • Every statistic is a rank correlation over a handful of patients. Read the grid for pattern across scopes, not for significance.
  • The populations overlap (CD8T sits inside Cytotoxic, T_total and Immune_total), so their rho values are not independent.
  • Immune_other puts the sum of quanTIseq’s B, macrophage, monocyte, dendritic and neutrophil fractions against every CD45+ CD3− CD56− cell; NonImmune puts quanTIseq’s uncharacterized cell against every CD45− cell.
  • An annotation scope changes the IHC side only. The bulk RNA is one sample per patient and is the same in all four scopes.
  • massimo1_inverted has no scope here: it re-classifies massimo1’s cells and borrows its polygons, so it is a third phenotyping rather than a third annotation.
